# Auth & route-exposure audit (Session 2)

Written 2026-10-16 against the **live running network** (sequencer :3030, replicas :3031/:3032, member :4001, prescriber :4002, pharmacy :4003, insurer+marketplace :4004, explorer :8000, employer tenants :65441/:65445, HR Tools :65442/:65446) and the working tree. Audited against owner rules **I7** (every route that changes state or returns member data must authenticate its caller) and **I4** (nothing outside the app can reach the app's functions/data). `file:line` citations re-checked against source this session. No source file was modified.

**Live baseline confirmed:** admin registry empty (`l2_getAdminKeys` → `[]`) → sequencer runs **Bearer mode**, Ed25519 admin dormant. Admin gate itself **works**: no-token → `-32003 Unauthorized`, wrong-token → `-32003`, correct bearer passes (`l2_deletePlan __nonexistent__` → `success:false`). Known member wallet used in probes: `20558…341277` (member node :4001's own wallet, has claims). Probes used read-only or bogus/nonexistent IDs only; the two "write" probes (`l2_storeMessage`, `l2_registerPcpAssignment`) used bogus wallet IDs `999…`/`777…`/`666…`, and `l2_requestAttestation` is a harmless signed-receipt append.
