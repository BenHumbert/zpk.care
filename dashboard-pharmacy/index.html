Pharmacy Onboarding

Step-by-step enrollment ceremony: accept token, generate key, derive wallet with NPI/NCPDP credentials, enroll, compile, ready.

1 Accept Token
2 Generate Key
3 Derive Wallet
4 Enroll
5 Compile
6 Done
Accept Group Enrollment Token
Enter the enrollment token provided by your employer or insurer group administrator.
Generate Enrollment Key
A cryptographic enrollment key will be generated locally on this device. It is NEVER transmitted.
Derive Pharmacy Wallet
Enter the pharmacy's service provider credentials. The wallet ID will be derived using Poseidon hashing with NPI or NCPDP qualifier.
Qualifier code per NCPDP standard
NPI, NCPDP, or other pharmacy identifier
Enroll with Insurer
Register the wallet with the insurer attestation authority. The insurer sees only the opaque wallet ID -- never your credentials or enrollment key.
Compile ZK Programs
Compile the zero-knowledge proving circuits. This may take 1-3 minutes depending on hardware.
Onboarding Complete
Your pharmacy node is fully enrolled and ready to process claims. Zero-knowledge circuits are compiled.
